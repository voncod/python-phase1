# Python Phase 1

## Objective

This repository contains the projects developed during my Python Phase 1 studies, with a focus on building practical programming and automation skills applicable to Cloud and Infrastructure environments.

The goal of this phase was not to become a Python developer, but to learn Python as a practical tool for automation, data processing, API interaction, and infrastructure-related tasks.

## Projects

### 01 — Server Health Report

Processes structured server data from a JSON file and generates a health report containing server status, environments, and servers requiring attention.

**Main concepts practiced:**

* Python fundamentals
* Lists and dictionaries
* Nested data structures
* JSON
* File handling
* Data processing

### 02 — API Health Monitor

Consumes an HTTP API, handles request and HTTP errors, processes the API response, and generates a health report.

**Main concepts practiced:**

* HTTP / REST APIs
* `requests`
* JSON
* YAML
* Exception handling
* Timeouts
* Configuration files

### 03 — File Automation

Automatically organizes files according to their extensions using Python filesystem automation.

**Main concepts practiced:**

* `pathlib`
* File and directory manipulation
* File extensions
* Dictionaries
* Conditional logic
* Filesystem automation

## Learning Approach

The projects in this repository were developed incrementally, with each project focusing on different Python automation capabilities.

Rather than building one large artificial application, the projects are intentionally small and independent. This makes it possible to practice individual concepts and gradually combine them into practical automation tasks.

## Notes

* This repository represents the conclusion of my initial Python studies.
* The projects are learning-focused and are not intended to be production-ready systems.
* Python is being studied as a tool for Cloud and Infrastructure automation.
* The next stage of the learning path will focus on technologies and concepts more directly related to Cloud and Infrastructure.
